Provisionning de VM

Ma contribution (Développement & Automatisation) :

  • Développement du backend en Python avec Flask, incluant la logique métier et la gestion des sessions utilisateurs
  • Mise en place de l'authentification via Microsoft Entra ID (OAuth), avec contrôle d'accès aux différents tableaux de bord en fonction du rôle (définis dans la base de données SQLite)
  • Conception et développement d'une API REST (endpoints Flask) pour assurer la communication entre l'interface web et Zapier : transmission des demandes, réception du statut de validation, et suivi de l'état des demandes en temps réel côté client
  • Développement en JavaScript des interactions côté client, notamment la gestion du bouton de demande déclenchant la notification du valideur
  • Mise en place d'un workflow d'automatisation avec Zapier : transmission des demandes vers un valideur humain, puis déclenchement automatique du provisioning sur Terraform une fois la demande approuvée
  • Déploiement et hébergement de l'application sur Render.com

Stack : Python (Flask), JavaScript, OAuth / Microsoft Entra ID, API REST, SQLite, Terraform, Zapier, Render.com
