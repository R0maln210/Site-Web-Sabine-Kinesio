# Site-Web-Sabine-Kinesio
Projet PPE consistant à refaire le site web de Sabine Jaquet-Gut

J’ai commencé par rechercher une approche plus corporate et professionnelle pour le site, sans pour autant dénaturer la direction artistique de départ. J’ai donc conservé les principaux éléments visuels, notamment le blanc et le vert, ainsi que les logos et les textes existants, tout en retravaillant leur disposition et leur présentation afin d’obtenir un résultat plus moderne, clair et cohérent.
